Compatible Clients

Every terminal agent, IDE extension, workflow tool, and chat platform that works with the ApiSpi LLM Gateway. The gateway is OpenAI-compatible, so anything that lets you set a custom base URL and API key works unmodified — one ApiSpi key instead of per-provider credentials.

Connecting Any Client

Two settings, the same for every tool below:

SettingValue
Base URLhttps://apispi.com/api/gateway/v1
API keyYour gateway key (gw_…) — create one at /dashboard/profile#api-keys

Requests route through the gateway with your governance applied and usage logged. Model choice follows the model resolution rules; see the Model Library for what's available. The live, maintained list with per-client setup guides is at apispi.com/clients.

Beyond OpenAI-Compatible

Clients that speak richer protocols get more than chat completions:

  • MCP clients (Claude Desktop, Claude Code, claude.ai custom connectors) — connect to /api/gateway/mcp and call your connected ApiSpi tools directly. See MCP & A2A.
  • ChatGPT — a Custom GPT with Actions from /openapi/gpt-actions.json. See API Gateway.
  • A2A agents — task exchange via /api/a2a with discovery through the published agent card.
