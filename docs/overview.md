# Platform Overview

ApiSpi is an agentic AI platform that deploys production-ready AI agents for government, enterprise, and professional services teams across Australia.

## Core Offerings

| Category | Description |
|---|---|
| **AI Agents** | Pre-built autonomous agents for specific business functions, available via monthly subscription |
| **Digital Avatars** | AI-powered video personas for client-facing professional services |
| **Training** | Hands-on workshops and online courses covering AI adoption for teams and leaders |
| **Aria** | AI assistant embedded in the platform, accessible to all authenticated users |

## Application Structure

The platform is a Laravel web application with:

- A **public-facing website** with an Aria chatbot widget, agent catalogue, checkout, and lead capture
- An **authenticated dashboard** providing access to subscribed agents, connector management, Aria (full AI assistant), and training
- An **admin panel** for managing users, subscriptions, agents, connectors, and content
