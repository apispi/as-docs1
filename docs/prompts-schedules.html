Prompts & Schedules

Prompts turn things you ask Aria repeatedly into reusable, one-click building blocks. Schedules run those prompts automatically — hourly, daily, or weekly — and deliver the results back into your Aria chat.

The Prompt Library

ApiSpi ships a curated library of prompts — browsable publicly at apispi.com/prompts (each prompt has its own page) and inside the dashboard at /dashboard/prompts, organised by category with tags.

  • Adopt a library prompt to copy it into My Prompts, where you can edit it freely
  • Rate prompts to surface the best ones for other users
  • Sync with catalog pulls in newly published library prompts at any time

My Prompts

Your personal prompt collection at /dashboard/prompts:

ActionHow
CreateNew Prompt → name it, write the body, pick a category. Anything you find yourself typing into Aria twice belongs here.
UseRun it straight into an Aria conversation — one click, no retyping.
FavouritePin the prompts you use most to the top.
Edit / DeleteAdopted library prompts become fully yours to change.
Writing a good reusable prompt: state the outcome, the format, and the sources. "Summarise my unread email from today; group by urgency; one line each" beats "check my email" — and it makes a far better schedule, because there's no follow-up conversation to have.

My Schedule

Schedules run a saved Prompt automatically, using the model you choose. Manage them at /dashboard/schedule.

Creating a schedule

  1. Save the prompt you want to automate to My Prompts first
  2. Go to My Schedule → create a schedule → pick the prompt and a model (the model picker offers the same choices as Aria — see Available Models)
  3. Choose the cadence:
    FrequencyRuns
    HourlyEvery hour, on the hour
    DailyEvery day at your chosen time
    WeeklyOn your chosen day of the week, at your chosen time
  4. Times are anchored to the timezone of your saved profile location, and each schedule's "Next" run is displayed in its own timezone — set your location under Profile → Personalisation before relying on run times

Living with schedules

  • Results arrive in Aria — badged as scheduled, so your briefing is waiting in the same chat you already use
  • Run now tests a schedule immediately without waiting for the next slot
  • Pause / resume with the toggle; edit or delete any time
  • Run History — every schedule has its own page with collapsible past runs, so you can see exactly what ran and when

Scheduled runs use the same connectors and are subject to the same governance (token limits, guardrails, tool rules) as live chat. If your organisation runs schedules at scale, admins can see health stats across all users' schedules and pause/resume any of them.
