Skills

A Skill is a packaged capability or persona prompt — distinct from both Agents and Connectors — that gets attached to one or more agents. Skills have no relationship to connectors.

Data Model

Model Skill, table skills: slug, name, description, category, is_active, sort_order. The base catalogue is seeded by SkillSeeder — 46 skills across 10 categories — with a further 20 industry skills (Front Office, Commerce & Retail, Trades & Field Services, and Communications & Front Office) added by the standalone agent seeders, for 66 skills across 14 categories.

Most skills carry a short one-line description. A subset (Forensic Analysis, Architecture Review, Technology Roadmapping, Decision Record Drafting, Architecture Pattern Matching, Avatar Generation, Voice Cloning, Market Mapping, Pricing Strategy) instead carry a full markdown system-prompt — these double as the actual prompt injected when the skill is active for an agent. The three persona skills (Shopping Agent, Digital Plumber, Digital Receptionist) are the full system prompts behind those agents.

Skill ↔ Agent Relationship

Skills attach to agents via a many-to-many pivot, agent_skill (with a definition column), seeded by AgentSkillSeeder. Each of the 18 agents is assigned 4–10 skills; some skills are reused across multiple agents (e.g. Document Analysis, Report Writing, Compliance Matrix Generation).

Example — Bid & Tender Response draws on: RFQ/RFT Parsing, CV Parsing, Document Analysis, STAR Response Generation, Executive Summary Writing, Capability Statement Writing, Compliance Matrix Generation, and Gap Analysis. The pattern repeats for the other agents — each draws on the skill category closest to its domain.

Skill Entitlement (Subscriptions)

Skills carry no price of their own. Entitlement is managed per subscription tier via the subscription_skill pivot (with an is_disabled flag) — gating which packaged capabilities a subscriber's agents can use, independent of which connectors that agent can call.

Relationship Summary

Agent ──< agent_skill >── Skill          (which packaged capabilities an agent has)
Agent ──< agent_connector >── Connector  (which tools/integrations an agent can call)
Subscription ──< subscription_skill >── Skill  (which skills a subscriber is entitled to)
