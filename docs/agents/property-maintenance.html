FAQs

Does it integrate with property management software?

Yes. It supports common property management systems and can import/export data via CSV and API.

Can it handle strata compliance requirements?

Absolutely. Generate strata meeting agendas, compliance checklists, and maintenance fund reports.

Does it support preventive maintenance scheduling?

Yes. Set up scheduled inspections and maintenance tasks with automated reminders and escalation workflows.
