Admin & Governance

Token Usage

Every Aria conversation turn is recorded in token_usage — user, connector, model, input/output tokens, prompt, reply, system prompt, and mode. The admin page shows a 30-day daily chart, totals by connector/model, and a filterable per-turn log. Connector tool-call activity is tracked separately in connector_usage_log (see Connectors).

Users see their own usage on the Usage/Token tabs of /dashboard/profile — remaining, lifetime, and consumed tokens per AI provider.

Governance

A single org-wide OrgPolicy row (OrgPolicy::current()) controls:

FieldEffect
contentFree text injected directly into Aria's system prompt on every conversation.
blocked_keywordsIf a user message or AI reply matches, the reply is swapped for a guardrail message and logged to the Activity Log as aria.guardrail.blocked.
daily_token_limitOnce a user's daily token total (TokenUsage::todayTotalForUser()) reaches this value, further Aria requests get a fixed "limit reached" reply instead of calling the model.
connectors_disabledGlobal kill switch — ignores everyone's saved AI connector config and falls back to the platform's Anthropic key, without altering individual user settings.
Governance enforcement happens inline in the chat controllers at message-send time — it is not a separate request-blocking middleware. daily_token_limit is enforced in ChatController, DashboardAriaChatController, and WorkspaceChatController alike, but blocked_keywords and connectors_disabled are currently checked only in ChatController and DashboardAriaChatController — not in Workspace chat.

AI Firewall

A separate, pattern-based detector (AiFirewallService::inspectRequest()) scans outbound gateway/connector request bodies for prompt injection and PII (email, credit card, API key patterns).

Detection only: the firewall never blocks or modifies a request — it logs matches for review and nothing more.

FirewallRule toggles each category on or off, either globally or scoped to a specific connector (a connector-level rule overrides the global one). Every match is recorded in FirewallLog — user, connector, direction, category, and a 200-character snippet — and reviewed in a filterable activity log on the same admin page.

Affiliate Program

Distinct from the formal Partner Program application, every registered user automatically gets a referral code (users.referral_code) and a shareable link: https://apispi.com/register?ref=<code>.

StepMechanism
CaptureCaptureReferral middleware reads ?ref= on any page and stores it in the session.
AttributionOn signup, users.referred_by is set if a valid referral code was captured.
ConversionAn AffiliateConversion row is created only when the referred user completes a paid action — a subscription or token purchase — via the Stripe webhook. Signups alone do not convert.
CommissionPurchase amount × a fixed config rate. Status starts pending.
PayoutAn admin bulk-marks all of a user's pending conversions paid from /admin/sales?tab=affiliates — there is no partial payout.

Users track their own referrals, conversions, and commission totals on the Affiliate tab of /dashboard/profile.
