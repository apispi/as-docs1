Subscription Management

Subscriptions are created via Stripe checkout. Users access subscribed agents from the dashboard at /dashboard/subscriptions.

Each subscription can have:

  • Skills — specific capabilities attached to an agent subscription.
  • Connectors — external service integrations enabled for the subscription.

Subscription statuses: active, paused, cancelled.
