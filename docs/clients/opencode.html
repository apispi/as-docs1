OpenCode

CLI for AI-powered development workflows; also usable from VS Code/Cursor via its extension.

Gateway Settings

SettingValue
Base URLhttps://apispi.com/api/gateway/v1
API keyYour gateway key (gw_…) — create one at /dashboard/profile#api-keys

On an On-Prem Appliance deployment, substitute your appliance's hostname for apispi.com.

Configuration

Run /providers (or /connect) inside opencode and add the gateway as a custom OpenAI-compatible provider, or configure it in ~/.config/opencode/config.json:

{
  "provider": {
    "apispi": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "ApiSpi Gateway",
      "options": { "baseURL": "https://apispi.com/api/gateway/v1" },
      "models": {
        "claude-sonnet-4-6": { "name": "Claude Sonnet 4.6" }
      }
    }
  }
}

Restart OpenCode after config changes. From VS Code/Cursor: install the OpenCode extension, then run "Open opencode" from the command palette.

Current v1 caveats (see LLM Gateway): responses are non-streaming, the model parameter maps to Anthropic models (claude-*; anything else falls back to the platform default), max_tokens is fixed at 1024, and the Responses API is not supported. Model IDs are case-sensitive — take them from the Model Library.
