Cursor

IDE supporting plan and agent mode through the gateway; some features stay on Cursor's own backend.

Gateway Settings

SettingValue
Base URLhttps://apispi.com/api/gateway/v1
API keyYour gateway key (gw_…) — create one at /dashboard/profile#api-keys

On an On-Prem Appliance deployment, substitute your appliance's hostname for apispi.com.

Configuration

  1. Cursor → Settings → Cursor Settings → Models
  2. Add OpenAI API Key → paste your gw_ key
  3. Enable Override OpenAI Base URL → https://apispi.com/api/gateway/v1

What Routes Through the Gateway

FeatureRouted?
AI panel (Cmd/Ctrl+L), plan modeYes
Agent-mode multi-file editsYes
Inline Edit (Cmd/Ctrl+K)No — locked to Cursor's backend
Tab autocompleteNo — locked to Cursor's backend

If you need every request governed, use Claude Code, Cline, or Continue CLI instead.

Current v1 caveats (see API Gateway): responses are non-streaming, the model parameter maps to Anthropic models (claude-*; anything else falls back to the platform default), max_tokens is fixed at 1024, and the Responses API is not supported. Model IDs are case-sensitive — take them from the Model Library.
