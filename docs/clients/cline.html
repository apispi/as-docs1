Cline

AI-powered coding assistance in VS Code via an OpenAI-compatible provider.

Gateway Settings

SettingValue
Base URLhttps://apispi.com/api/gateway/v1
API keyYour gateway key (gw_…) — create one at /dashboard/profile#api-keys

On an On-Prem Appliance deployment, substitute your appliance's hostname for apispi.com.

Installation

  1. VS Code → Extensions (Cmd/Ctrl+Shift+X) → search Cline → Install

Configuration

  1. Cline panel → gear icon → API Provider: OpenAI Compatible
  2. Base URL: https://apispi.com/api/gateway/v1
  3. API key: your gw_ key
  4. Model ID: e.g. claude-sonnet-4-6

Verify

Open a project, click the Cline sidebar icon, and ask for something like "Create a hello world function in Python" — Cline should respond and offer to create the file.

Current v1 caveats (see LLM Gateway): responses are non-streaming, the model parameter maps to Anthropic models (claude-*; anything else falls back to the platform default), max_tokens is fixed at 1024, and the Responses API is not supported. Model IDs are case-sensitive — take them from the Model Library.
