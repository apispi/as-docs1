Hermes Agent

Nous Research's terminal-based AI coding agent, configured via its setup wizard.

Gateway Settings

SettingValue
Base URLhttps://apispi.com/api/gateway/v1
API keyYour gateway key (gw_…) — create one at /dashboard/profile#api-keys

Installation

curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash
source ~/.bashrc && hermes --version

Configuration

hermes setup

In the wizard choose Custom OpenAI-compatible endpoint, enter base URL https://apispi.com/api/gateway/v1 and your gw_ key, pick a model, and choose a terminal backend (Local, Docker, SSH…).

Settings live in ~/.hermes/config.yaml, keys in ~/.hermes/.env. Diagnose connection issues with hermes doctor.

Current v1 caveats (see API Gateway): responses are non-streaming, the model parameter maps to Anthropic models (claude-*; anything else falls back to the platform default), max_tokens is fixed at 1024, and the Responses API is not supported. Model IDs are case-sensitive — take them from the Model Library.
