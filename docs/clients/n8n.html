n8n

Workflow automation platform — add governed AI steps to any workflow.

Gateway Settings

SettingValue
Base URLhttps://apispi.com/api/gateway/v1
API keyYour gateway key (gw_…) — create one at /dashboard/profile#api-keys

On an On-Prem Appliance deployment, substitute your appliance's hostname for apispi.com.

Credential Setup

  1. n8n → Settings → Credentials → Add Credential → OpenAI
  2. API Key: your gw_ key
  3. Base URL: https://apispi.com/api/gateway/v1
  4. Organization ID: leave blank

Node Configuration

  1. Add an AI Agent node and connect a Chat Model edge
  2. Select the credential you created
  3. Toggle off the Responses API on the model node — the gateway supports chat completions only
  4. Set the model (e.g. claude-sonnet-4-6) and any LLM options

Run the workflow with a test prompt to verify.

Current v1 caveats (see LLM Gateway): responses are non-streaming, the model parameter maps to Anthropic models (claude-*; anything else falls back to the platform default), max_tokens is fixed at 1024, and the Responses API is not supported. Model IDs are case-sensitive — take them from the Model Library.
