Kilo Code

VS Code integration for autonomous AI coding with built-in provider support.

Gateway Settings

SettingValue
Base URLhttps://apispi.com/api/gateway/v1
API keyYour gateway key (gw_…) — create one at /dashboard/profile#api-keys

On an On-Prem Appliance deployment, substitute your appliance's hostname for apispi.com.

Installation

  1. VS Code (or any VS Code-based editor, incl. Cursor/Windsurf) → Extensions → search Kilo Code → Install

Configuration

  1. Kilo Code sidebar icon → Settings → Providers
  2. Add an OpenAI-compatible provider with base URL https://apispi.com/api/gateway/v1 and your gw_ key
  3. Pick the model from the picker at the bottom of the chat panel
Current v1 caveats (see API Gateway): responses are non-streaming, the model parameter maps to Anthropic models (claude-*; anything else falls back to the platform default), max_tokens is fixed at 1024, and the Responses API is not supported. Model IDs are case-sensitive — take them from the Model Library.
