OpenClaw

AI-powered chat across Discord, WhatsApp, Telegram, and more — governed and logged by ApiSpi.

Gateway Settings

SettingValue
Base URLhttps://apispi.com/api/gateway/v1
API keyYour gateway key (gw_…) — create one at /dashboard/profile#api-keys

Setup

export APISPI_API_KEY=gw_your_api_key_here

Add the gateway as a custom provider in ~/.openclaw/openclaw.json:

{
  "models": {
    "mode": "merge",
    "providers": {
      "apispi": {
        "baseUrl": "https://apispi.com/api/gateway/v1",
        "apiKey": "${APISPI_API_KEY}",
        "api": "openai-completions",
        "models": [
          { "id": "claude-sonnet-4-6", "name": "Claude Sonnet 4.6",
            "contextWindow": 200000, "maxTokens": 8192 }
        ]
      }
    }
  },
  "agents": {
    "defaults": { "model": { "primary": "apispi/claude-sonnet-4-6" } }
  }
}

Reference models as apispi/<model-id>.

Current v1 caveats (see API Gateway): responses are non-streaming, the model parameter maps to Anthropic models (claude-*; anything else falls back to the platform default), max_tokens is fixed at 1024, and the Responses API is not supported. Model IDs are case-sensitive — take them from the Model Library.
