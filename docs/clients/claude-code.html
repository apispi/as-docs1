Claude Code

AI-powered terminal assistance and coding — connects to the ApiSpi gateway two ways: the Anthropic proxy for chat, and MCP for your connected tools.

Gateway Settings

SettingValue
Base URLhttps://apispi.com/api/gateway/v1
API keyYour gateway key (gw_…) — create one at /dashboard/profile#api-keys

On an On-Prem Appliance deployment, substitute your appliance's hostname for apispi.com.

Setup (Anthropic proxy)

No installation needed beyond Claude Code itself — it speaks the Anthropic wire format, so point it at the gateway's Anthropic proxy (your Anthropic key is injected server-side):

export ANTHROPIC_BASE_URL=https://apispi.com/api/gateway/anthropic
export ANTHROPIC_AUTH_TOKEN=gw_your_api_key_here
export ANTHROPIC_MODEL=claude-sonnet-4-6   # optional

claude

Setup (MCP — connected tools)

Alternatively (or additionally), connect over MCP so Claude Code can call your connected ApiSpi tools directly:

claude mcp add apispi --transport http https://apispi.com/api/gateway/mcp \
  --header "Authorization: Bearer gw_your_api_key_here"
Current v1 caveats (see LLM Gateway): responses are non-streaming, the model parameter maps to Anthropic models (claude-*; anything else falls back to the platform default), max_tokens is fixed at 1024, and the Responses API is not supported. Model IDs are case-sensitive — take them from the Model Library.
