Autohand Code

Autonomous AI-powered coding across terminal, IDE, and Slack — configured with two environment variables.

Gateway Settings

SettingValue
Base URLhttps://apispi.com/api/gateway/v1
API keyYour gateway key (gw_…) — create one at /dashboard/profile#api-keys

Setup

export OPENAI_BASE_URL=https://apispi.com/api/gateway/v1
export OPENAI_API_KEY=gw_your_api_key_here

autohand

With the environment set, all Autohand commands (multi-file editing, agentic search, autonomous generation) work as normal through the gateway.

Current v1 caveats (see API Gateway): responses are non-streaming, the model parameter maps to Anthropic models (claude-*; anything else falls back to the platform default), max_tokens is fixed at 1024, and the Responses API is not supported. Model IDs are case-sensitive — take them from the Model Library.
