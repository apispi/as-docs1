Connectors

Connectors are integrations with external services that extend Aria's capabilities and power agent functionality. Each connector is defined in the connectors table and linked to users via user_connectors.

Connector Types

API Key Connectors

The user provides an API key (and optionally other config values). Keys are stored in user_connectors.config and used directly in tool calls.

Examples: Anthropic, Google Gemini, SCX AI, Substack.

OAuth Connectors

The user completes an OAuth flow. Tokens are stored in connector_tokens and automatically refreshed via OAuthService::getValidToken(). OAuth flows are handled by ConnectorOAuthController.

Examples: Microsoft 365, Gmail.

RouteAction
GET /connectors/{slug}/authorizeStart the OAuth redirect.
GET /connectors/{slug}/callbackReceive the token after consent.
POST /connectors/{slug}/disconnectRevoke the user's token.

Tool Definitions Format

A connector's tool_definitions field is a JSON array of tool schemas in Anthropic's tool format. When Aria builds its tool list it merges definitions from all active connectors. The internal fields _connector_slug and _connector_config are stripped before being sent to any LLM.

[
  {
    "name": "tool_name",
    "description": "What this tool does.",
    "input_schema": {
      "type": "object",
      "properties": {
        "param": { "type": "string", "description": "..." }
      },
      "required": ["param"]
    }
  }
]

Tools Exposed Per Connector

Only connectors with non-empty tool_definitions expose callable tools to Aria's tool-use loop. AI-provider connectors configure which model answers, not callable tools, so they have none. See connectors.md in the repo root for the full per-connector tool list (Gmail, Substack, BOM, Open-Meteo, AccuWeather, World Time, WhatsApp, Generic Website, Neo4j, SCX, Argyll, OpenAI, Copilot, Data.gov.au, Facebook, LinkedIn, Defender, Teams, OneDrive, Pega, Power BI, Salesforce, SAP S/4HANA, SAP SuccessFactors, ServiceNow, SharePoint, Stripe, Twilio, USASpending, VirusTotal, Woolworths, Workday, Xero, YouTube, AbuseIPDB, AWS, Amazon Product Search, the news connectors — ABC, CNA, Japan Times, Jerusalem Post, NYT, Washington Post, Xinhua, Ground News — and the generic Microsoft connector). Gmail now supports reading full messages, threaded replies, and drafts, with header-injection defence.

Starter Connectors

New accounts are provisioned with a set of no-key starter connectors (news, BOM and Open-Meteo weather, World Time) so Aria is useful before any credentials are configured. Existing accounts were backfilled when starters were introduced.

MCP & A2A Connectors

External MCP servers and A2A (agent-to-agent) endpoints can be registered as first-class connectors, importing their tool lists into the catalogue so their tools behave exactly like native ones. See MCP & A2A for how discovery and execution work.

API Gateway & Keys

Connectors are also reachable programmatically over a Bearer-authenticated proxy, unified tool-invocation, and OpenAI-compatible endpoint — without managing upstream OAuth tokens or API keys directly. See the dedicated API Gateway page for endpoints, key management, auth resolution, and usage logging.
