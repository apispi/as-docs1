Connectors

Connectors are integrations with external services that extend Aria's capabilities and power agent functionality. Each connector is defined in the connectors table and linked to users via user_connectors.

Connector Types

API Key Connectors

The user provides an API key (and optionally other config values). Keys are stored in user_connectors.config and used directly in tool calls.

Examples: Anthropic, Google Gemini, SCX AI, Substack.

OAuth Connectors

The user completes an OAuth flow. Tokens are stored in connector_tokens and automatically refreshed via OAuthService::getValidToken(). OAuth flows are handled by ConnectorOAuthController.

Examples: Microsoft 365, Gmail.

RouteAction
GET /connectors/{slug}/authorizeStart the OAuth redirect.
GET /connectors/{slug}/callbackReceive the token after consent.
POST /connectors/{slug}/disconnectRevoke the user's token.

Admin management

Admins manage the connector catalogue at /admin/connectors and assign connectors to users at /admin/users/{user}/connectors.

Tool Definitions Format

A connector's tool_definitions field is a JSON array of tool schemas in Anthropic's tool format. When Aria builds its tool list it merges definitions from all active connectors. The internal fields _connector_slug and _connector_config are stripped before being sent to any LLM.

[
  {
    "name": "tool_name",
    "description": "What this tool does.",
    "input_schema": {
      "type": "object",
      "properties": {
        "param": { "type": "string", "description": "..." }
      },
      "required": ["param"]
    }
  }
]
