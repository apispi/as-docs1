Workspaces

A workspace is a shared team chat space — one Aria conversation thread visible to every member — not a private project container. Any authenticated user can create one.

Data Model

TableKey fields
workspacesname, unique slug, unique invite_code, owner_id (FK users, cascade delete)
workspace_membersworkspace_id + user_id (unique pair), role (owner or member), ai_enabled (boolean, default false)
workspace_messagesworkspace_id, nullable user_id, user_name, role, content, tool_calls (JSON), active_agents (JSON)

There is exactly one shared message stream per workspace — every member reads and writes the same thread.

Create or Join

  • /dashboard/workspaces — list your workspaces and create a new one (auto-generates a unique slug and invite_code)
  • /dashboard/workspaces/join/{inviteCode} — join via an invite link

Membership & Roles

Only two roles exist — owner and member. There is no separate admin/moderator tier.

ActionWho can do it
Invite new membersAny member
Toggle their own AI settingAny member
Send chat messagesAny member
Clear the entire shared historyAny member (removes it for everyone)
Remove another memberOwner only
Be removedThe owner cannot be removed

Chat

The Chat tab polls for new messages every few seconds, supports file attachments, and shows tool-call badges for any connector tool the AI used while generating a reply. Sending a message is not gated by anything member-specific.

Per-Member AI Toggle

ai_enabled does not control whether a member can chat. It controls whether that member's personal AI connector/personalisation settings are folded into the assistant's shared reply when it responds in the thread. It defaults to off.

Token Usage & Governance

Workspace chat reuses the same connector/tool pipeline as dashboard Aria chat (WorkspaceChatController shares the RunsAgentTools trait with DashboardAriaChatController) and logs to token_usage the same way, tagged as a workspace conversation.

The org-wide daily token limit (see Admin & Governance) still applies per user inside a workspace. The blocked-keyword guardrail and the connectors-disabled kill switch are currently dashboard-chat-only and are not enforced in workspace chat.
